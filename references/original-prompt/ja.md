# XXD Panel 040 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、ライフスタイル雑誌、インディペンデント出版物、アート写真のような質感を持たせます。画面比率に合わせるため、環境背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、まず元画像の真の**視覚的核心と寓意**を理解します。画面で最も重要なのは「何があるか」ではなく、「何が最も記憶に残る価値があるか」だと見極めます。それは、1つの被写体、1つの動作、一組の関係性、1か所のコントラスト、感情の一瞬、または何らかの象徴的意味かもしれません。そこから最も識別性の高い**被写体、輪郭、姿勢、空間関係、物語の手がかり**を抽出し、「リアルな被写体＋黒線の落書き風の小人」による遊び心のあるエディトリアルポスターとして再構成します。元画像で最も大きな物体を機械的に切り取るのではなく、写真の精神と物語性を最もよく表す視覚的アンカーを残し、下半分が一目で元画像に対応すると同時に、元画像に知的な再解釈を施したように見えるようにします。

リアルな被写体は素材感とアイデンティティを示す特徴を保ち、核となる特徴がより鮮明になるよう、角度、比率、光、色彩を適度に最適化できます。元画像のうち寓意と無関係な情報は省けますが、テーマを支える重要な関係性は必ず残します。被写体の周囲に少量の極めてミニマルな黒線の落書き風の小人を加えます。小人の動作、位置、関わり方は、元画像の形態、文脈、潜在的な寓意に基づいて完全に自然に生成し、無作為に動作をさせるのではなく、写真本来の物語に応答し、それを増幅し、または反転させているかのようにします。

配色は上の写真から最も識別性と生気のある色を抽出し、適度に純化し、明るくし、再編成できます。背景はオフホワイト、淡色、または元画像の中で最も心地よい淡色を主体とし、大きな余白を保ちます。リアルな被写体が主要な色彩を担い、小人と文字は黒またはダークグレーの細い線でコントラストを作り、全体をクリーンで軽快かつ抑制の効いたものにします。

文字も同様に、元画像の**核心的な寓意、感情、視覚的関係**から自然に生まれるものとし、物体の名称を直接説明したり、定型文を当てはめたりしません。写真の中で最も記憶に残す価値のある意味の層を、ごく短く、気軽で、知的で、わずかにユーモアや言葉遊びを含む手書き文字に変換し、小人が残した注釈、考え、または一言のナレーションのように見せます。文字は被写体の輪郭、小人の動作、または余白のリズムに沿って自由に配置でき、小人と被写体とともに物語を完成させ、後から貼り付けたタイトルにはしません。

全体として、**リアルな被写体、核心的な寓意、ミニチュアの物語、素朴な線、大きな余白**のバランスを保ちます。元画像が人物、動物、植物、食べ物、建築物、器物、乗り物、自然風景のいずれであっても、まず「この写真が本当に語っていることは何か」を捉え、それから再構成の方法を決めます。物体だけを捉えて関係性を捉えないこと、テーマのない可愛いだけのやり取り、カートゥーンステッカー感、複雑な装飾、テンプレート感は避けます。
