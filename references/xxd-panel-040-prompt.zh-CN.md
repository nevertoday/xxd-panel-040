# XXD Panel 040 · 完整生成提示词（中文）

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

严格把当前选定的一张照片作为唯一内容来源。每个所选普通模式都为它生成一张独立成品；四端壁纸套装生成手机、iPad、电脑、儿童手表四张独立 PNG。不要混入其他照片，不要把多张结果拼成一张总图。

成品使用调用方已经锁定的一个或多个模式：上方摄影＋下方微型叙事设计、左侧摄影＋右侧微型叙事设计、只显示变化设计，和／或四端壁纸。双联是一组等分面板（上下两格或并置两格），两格视觉上大致等分即可，轻微偏差可以接受；只有用户明确要求像素级对半时才需严格执行；纯设计版和壁纸不显示原照片，也没有分界线。正式生图前必须已经明确自动文案、自定义文案或无文字；有文字时必须已经明确目标语言或地区。

下文统一把承载“真实主体＋黑线涂鸦小人”的区域称为**变化画框**。

## 0. 美学动机锁

模式、尺寸和设备只能改变位置与画幅，不能改变 040 的核心：

**照片最值得被记住的主体、动作、关系、反差、情绪瞬间或象征意味 → 一个真实且可辨认的视觉锚点 → 少量黑线小人以动作回应、放大或轻轻反转原意 → 从源图提取的浅色空间与重点颜色 → 大量主动留白 → 一句像小人留下的手写注释、念头或画外音，让观众重新看懂照片。**

不要机械选取照片里最大的物体。先判断“这张照片真正讲的是什么”，再选择最能承载它的真实主体或不可拆分关系。成品必须像一次聪明、轻巧、有依据的二次解读，而不是给抠图主体贴上几个人物贴纸。

如果换一张无关照片，真实锚点、人物互动、空间关系、色彩和文案几乎不用改变，则成品失败。严格避免任意爬、坐、挥手的小人，通用可爱互动，密集涂鸦，贴纸感，素材库剪贴画，儿童绘本卡通，表情包，复杂装饰，拼贴阴影和模板广告。

所有画面必须通过可用的位图生图或编辑能力完成并以 PNG 交付。“黑线涂鸦、手写文字、平面构图”只描述外观，不授权 SVG、HTML、Canvas 或程序绘图替代生图。

## 1. 同一照片的两个角色

1. **双联模式里的摄影原片**：位于上方或左侧。保留主体结构、身份、真实材质、自然光影、镜头透视和原有色彩氛围，只允许轻微高级摄影调色。源图自适应时完整原图直接进入同尺寸面板，不裁切、不拉伸、不重绘。
2. **变化画框的事实依据**：提供叙事核心、真实锚点、轮廓、姿态、方向、比例、材质、空间关系、关键负形、重点颜色与潜在寓意。纯设计版和壁纸只使用这个角色，原照片本身不出现在结果中。

唯一允许的第二视觉参考是 `LINKED / 连贯套装` 中已经验收的定调壁纸。它只锁定视觉家族，不提供新内容；原照片始终是主体、关系和寓意的唯一事实来源。

## 2. 内部解读方法

在内部完成，不输出分析：

**观察事实 → 找到关系 → 提炼寓意 → 选择真实锚点 → 设计小人互动 → 提取颜色 → 创作文案 → 检查绑定度**

1. 记录确实可见的主体、动作、朝向、距离、遮挡、材质、光线与空间关系。
2. 判断最值得记住的是物体本身，还是等待、靠近、支撑、错开、对抗、循环、失衡、保护、尺度反差等关系。
3. 从前两层提炼一个有画面证据的语义核心。不得虚构人物经历、地点、归属、所有权、事件或心理。
4. 选择一个真实视觉锚点；只有不可拆分的关系才保留多个真实元素。锁定至少三个源图专属身份线索。
5. 让一至五个微型小人的动作与锚点轮廓、孔洞、结构、方向、尺度或留白直接发生关系。
6. 让文案完成同一个意思，而不是另起一个主题。

## 3. 真实摄影区域（仅双联模式）

- 保留真实结构、比例、面貌、姿态、材质、自然光影、透视与原色氛围。
- 只做克制的曝光、对比、高光、阴影、色温和纯度整理，使其接近生活方式杂志、独立出版物和艺术摄影。
- 用户指定的非自适应画框需要补足空间时，只自然扩展天空、地面、水面、墙面或环境；延展必须连续。
- 不拉伸、压扁、扭曲、替换服装、重塑五官、改变姿态或身份；不使用激进裁切。
- 摄影区域不得出现标题、小人、贴纸、编号或排版。
- 避免 HDR、过度磨皮、强锐化、赛博色调、重滤镜和明显生成痕迹。

## 4. 变化画框：真实锚点

- 锚点保持摄影真实感、材料身份和关键色彩。允许独立出来、调整取景、轻微重照明、适度强调比例，但不能扁平卡通化或被通用物体替代。
- 至少保留三个身份线索：外轮廓、姿态／方向、比例、材质、颜色、叠压、孔洞、负形、连接方式或关系距离。
- 人物保留身份可辨的轮廓、姿态、服装大形与动作；动物保留体态、头部方向和典型外形；植物保留生长方向和枝叶群关系；食物保留形态、质地与切面；建筑保留天际线、开口和关键结构；器物与交通工具保留功能轮廓、负形和朝向；自然场景选择一处真实地形、岩石、水体、云、树或其他可承载寓意的具体锚点。
- 删除与寓意无关的背景杂讯，但必须保留支撑主题的关系、接触点、尺度或方向线索。
- 锚点承担主要色彩和真实质感，始终是唯一主视觉；小人、文字和辅助线只能服务它。

## 5. 黑线涂鸦小人

- 通常使用一至五个极简小人，线条为黑色或深灰，细、略稚拙、手绘感明显但动作清楚。
- 人体结构只保留圆头、躯干、四肢、姿态、重心和必要的小道具；缩略图里仍应读得出在做什么。
- 每个动作都必须回答一个问题：它如何回应、放大、解释或反转原照片的核心关系？答不出来就删除。
- 小人可以观察、搬运、支撑、修补、测量、倾听、等待、追随、躲避、平衡、穿越或借用锚点结构，但只能在这些行为确实服务语义时使用。
- 小人应把锚点的轮廓、开口、表面、边缘、方向或尺度当作真实舞台；不要悬空贴在旁边。
- 不画详细五官、服装、阴影或彩色卡通身体；不用粗漫画描边、光滑矢量吉祥物、emoji、贴纸白边、重复姿势和装饰性人群。

## 6. 色彩、留白与手写文字

### 6.1 色彩与空间

- 背景使用米白、暖白、浅灰、浅色或原图最舒适的浅色；保持干净且有纸面呼吸感。
- 真实锚点承担源图最有辨识度和精气神的颜色，可适度提纯、提亮、重组，但不能与原图失去关系。
- 小人与大多数文字使用黑色或深灰细线。必要时只用一处小面积源图强调色连接锚点、人物与文字。
- 通过比例、位置、距离和大量主动留白建立节奏；不要用复杂纹理、花边、色块堆叠或填满空间来制造“设计感”。
- 避免霓虹、糖果卡通色、脏灰、无来源互补色、连续渐变、玻璃拟态、明显 3D、投影卡片和商业 UI。

### 6.2 文案逻辑

文案像小人写下的注释、念头或一句画外音，必须与锚点和动作共同完成叙事。

优先级：明确无字 > 用户最终成稿 > 用户方向或可编辑草稿 > 根据源图自动创作。

- 自动文案先读取表层事实、关系张力和有证据的潜在含义，再用精准命名、克制陈述、双重含义、轻幽默或小反转提炼一句极短文字。
- 不直接解释物体名称，不写广告口号、励志金句、煽情故事、强行谐音梗或空泛的“梦想／记忆／旅程”。
- 执行换图测试：换成无关照片仍成立的文字必须重写。
- 主文字优先一个短语或一句很短的话；按需要增加一至三条微型注释。所有文字延续同一个语义核心。
- 用户给出最终成稿时逐字保留，不改写、不翻译、不增删。用户给的是方向或草稿时，只在授权范围内精炼。
- 不擅自编造年份、地点、编号或档案信息。

目标语言优先级：**目标市场／受众 > 指定成品语言 > 用户方向语言；都不明确时生图前询问。** 本地化是转创而非直译，必须使用目标语言自然的表达、标点、空格、字形和断行。不得根据人物外貌、服装、场景或招牌猜测语言。

### 6.3 排版行为

- 文字可沿锚点轮廓、小人动作、引导线或留白节奏排布，像场景内部自然出现的笔记。
- 手写感轻松、聪明、略稚拙但必须准确可读；不能变成幼儿字体、涂鸦墙或无法辨认的伪文字。
- 主文字明显大于微型注释，但不必做成传统海报巨型标题。
- 不使用标题框、网页标签、投影、描边、渐变字、3D 字和无意义装饰字。

将锁定文案以以下格式附在生图提示词末尾：

```text
COPY MODE: REQUIRED
COPY ORIGIN: USER_EXACT | USER_DIRECTION | SOURCE_DERIVED
COPY LOCALE: <目标地区>
COPY INTENT — INSTRUCTION ONLY, NEVER RENDER: <语义核心与预期转折>
MAIN LINE: <锁定文字>
MICRO NOTE 1: <可选>
MICRO NOTE 2: <可选>
MICRO NOTE 3: <可选>
COPY RULE: 只渲染 MAIN LINE 和已有的 MICRO NOTE，每条恰好一次。其他字段只作指令，绝不出现在画面中。不得改写、翻译、纠错、重复或新增文字；遵守目标语言的字形、标点、空格与语义断行。
```

删除未使用的注释行。无字模式只附：`COPY MODE: NONE — render no text or pseudo-text anywhere.`

## 7. 模式、尺寸与壁纸

生成前锁定一个或多个模式，并明确每个普通模式的整张最终成品画幅。接受原提示词 3:4、明确跟随原图、常用比例或自定义比例／准确像素；不得静默采用源图尺寸。

1. **TOP_BOTTOM**：用已确认的整张画幅一次生成；高保真原图约占上半区，040 变化设计约占下半区，两区在色彩、节奏、文字与含义上统一。
2. **LEFT_RIGHT**：用已确认的整张画幅一次生成；高保真原图约占左半区，040 变化设计约占右半区，形成完整设计。
3. **DESIGN_ONLY**：原图只作为内容与身份依据，变化设计铺满已确认的整张画布，不显示原片或预留区。
4. **WALLPAPER_PACK**：手机、iPad、电脑、儿童手表四张独立变化设计；必须锁定 `INDEPENDENT` 或 `LINKED`。

精确像素优先于明确比例；两者都不能静默推导。壁纸只有用户明确选择常用预设时才使用手机 `1440×3200`、iPad `2048×2732`、电脑 `3840×2160`、手表 `1024×1024`，否则逐设备确认。

- **INDEPENDENT**：四张都只参考原照片，允许更自由的构图变化。
- **LINKED**：默认先生成并验收 iPad 定调图；其他三张都直接参考原照片＋同一张定调图，禁止顺序垫图和机械改尺寸。

运行时模式块使用文首“完整画布契约”中的 `FINAL CANVAS` 与 `SINGLE COMPLETE CANVAS` 结构。

## 8. 生成与合成边界

- 双联把原图作为高保真编辑／参考输入，与完整 040 美学提示词及锁定文案一起，一次生成整张成品。
- 约 50/50 是构图目标；整体色彩、光线、节奏、排版和语义优先于机械缝线精度。
- 只在完整画布针对性重试仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才分别准备摄影与设计资产并调用脚本兜底。
- 纯设计和四端壁纸都以完整最终画布生成；壁纸逐设备重构，不能裁切其他设备成品。
- 所有结果必须重新打开，以正常尺寸和缩略图检查语义、锚点、小人动作、文案准确度、画幅与壁纸安全区。

## 9. 出图前检查

1. 当前调用只处理一张明确源图，输出数量与所选模式集合一致：每个普通模式一张，所选壁纸模式四张，“全部”共七张且分处四个同级文件夹。
2. 最值得记住的不是机械选出的最大物体，而是有事实依据的核心主体或关系。
3. 真实锚点保留至少三个源图专属身份线索、真实材质与主色。
4. 每个小人的动作都直接服务同一个寓意；删除任何纯装饰动作后，画面应更准确而不是更空。
5. 背景浅而舒适，锚点承担主要颜色，黑线人物与文字形成清楚对比，留白主动且充足。
6. 自动文案轻、短、聪明、有绑定度，不直说物体，不套模板；自定义文案逐字正确；无字模式没有任何伪文字。
7. 双联呈现大致等分的两格面板且摄影真实；纯设计和壁纸没有照片、分界线或占位。
8. 连贯壁纸的定调图先通过验收，其他三张都直接参考同一锚点和原照片；四张分别重构。
9. 最终交付为实际 PNG 位图，不是 SVG、HTML、Canvas 或程序绘图。
10. 没有拼贴、贴纸感、模板感、Logo、水印、UI、设备样机或无关装饰。
